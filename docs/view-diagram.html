📖 Hướng dẫn xem sơ đồ PlantUML

Cách 1: Online Viewer (⭐ Nhanh nhất - Không cần cài đặt)

  1. Mở file use-case-diagram.puml bằng Notepad/VS Code
  2. Copy toàn bộ nội dung (Ctrl+A → Ctrl+C)
  3. Truy cập: http://www.plantuml.com/plantuml/uml/
  4. Paste vào ô text và nhấn "Submit"
  5. Xem sơ đồ và download nếu cần (PNG, SVG, PDF)
Mở PlantUML Online

Cách 2: VS Code Extension (⭐ Cho lập trình viên)

Bước 1: Cài extension

  1. Mở VS Code
  2. Vào Extensions (Ctrl+Shift+X)
  3. Tìm "PlantUML" by jebbs
  4. Click Install

Bước 2: Cài Java (Yêu cầu)

  1. Download Java JRE/JDK: https://www.java.com/download/
  2. Cài đặt Java
  3. Restart VS Code

Bước 3: Xem sơ đồ

  1. Mở file .puml trong VS Code
  2. Nhấn Alt + D hoặc chuột phải → "Preview Current Diagram"
  3. Sơ đồ hiển thị bên cạnh

Cách 3: IntelliJ IDEA / PyCharm

  1. Vào Settings → Plugins
  2. Tìm "PlantUML Integration"
  3. Install plugin
  4. Mở file .puml → Sơ đồ tự động hiển thị

Cách 4: Command Line (Advanced)

# Cài PlantUML qua npm
npm install -g node-plantuml

# Render thành PNG
puml generate docs/use-case-diagram.puml -o docs/

# Hoặc dùng Java (download plantuml.jar trước)
java -jar plantuml.jar docs/use-case-diagram.puml
