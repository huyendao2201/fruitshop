### Bước 1: Copy nội dung sơ đồ
1. Mở file `use-case-diagram.puml` trong thư mục này
2. Nhấn **Ctrl+A** (Select All) → **Ctrl+C** (Copy)

1. Truy cập: **http://www.plantuml.com/plantuml/uml/**

5. ✅ Sơ đồ hiển thị ngay!

- Click **"PNG"** để tải ảnh

## ❓ FAQ

**Q: Tại sao không thấy ảnh PNG/JPG trong thư mục?**  
A: File `.puml` là source code của sơ đồ. Cần render bằng PlantUML để ra ảnh.

**Q: Có cần cài PlantUML không?**  
A: Không bắt buộc. Dùng online viewer là nhanh nhất.

**Q: File .puml mở bằng gì?**  
A: Notepad, VS Code, hoặc bất kỳ text editor nào.

**Q: Tại sao sơ đồ không hiển thị đúng?**  
A: Đảm bảo copy toàn bộ nội dung từ `@startuml` đến `@enduml`.

**Q: Có thể chỉnh sửa sơ đồ không?**  
A: Có! Edit file `.puml`, sau đó render lại.
